**开发者：** Sniper276  
**版本：** v1.3 (Stable)  
**定位：** 轻量级、无依赖、高效的离线记忆强化工具。

---

## 🛠 项目架构
为了保证系统的可维护性与扩展性，本项目采用了**松耦合**的模块化设计：

-   `index.html`：系统的骨架，承载所有交互界面。
-   `style.css`：视觉系统，包含响应式布局与成就感动画（如金色发光效果）。
-   `app-config.js`：全局状态机，管理存档版本与核心数据结构。
-   `app-utils.js`：算法中枢，包含 **Fisher-Yates 随机洗牌算法**与**模糊重叠度评分算法**。
-   `app-ui.js`：界面驱动，负责 DOM 的动态渲染与实时统计更新。
-   `app-core.js`：流程控制器，处理“学习-复写-反馈”的循环逻辑。
-   `features.js`：增强插件，集成搜索系统与键盘快捷键。

---

## ✨ 核心功能
1.  **交替记忆逻辑**：背完题 N 后背题 N+1，接着强制默写题 N。利用“记忆干扰”原理，将短期瞬时记忆转化为长时记忆。
2.  **模糊字符评分**：针对语音输入识别不准的特点，采用 70% 字符重叠度算法。只要核心关键词字迹/发音对上了，系统即判定通过。
3.  **荣誉统计系统**：累计时长、累计默写字数、累计练习次数。让每一秒的努力都变成存档里可视化的数据。
4.  **去后端化设计**：完全基于 `LocalStorage` 存储，无需联网。支持通过 JSON 代码手动备份与迁移存档，永不丢号。
5.  **全局搜索与强化**：一键搜索知识点，支持“已会本”与“错题本”管理，实现精准复习。

## ⚖️ 核心原则（Principles）
无论未来如何发展，本系统将始终坚守以下三大原则：

### 一、 隐私与本地优先（Privacy First）
用户的学习数据是极其珍贵的资产。系统必须始终坚持**离线可用**，不强制联网，不收集用户信息。存档权必须牢牢掌握在用户自己手中（手动导出 JSON）。

### 二、 纯粹与专注（No Distraction）
背诵需要深度进入“心流”状态。系统严禁加入任何广告、社交干扰或冗余功能。每一像素的设计都必须为“提高背诵效率”服务。

### 三、 算法服务于人（Human-Centric Algorithms）
算法应具有温度。评分系统应具备容错性（如已实现的模糊匹配），目的是鼓励用户开口背诵，而非因个别错别字产生挫败感。系统应是“助学伙伴”而非“严苛考官”。
